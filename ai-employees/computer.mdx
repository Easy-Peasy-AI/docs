title: "The employee's computer"
description: "Each employee works on a computer of its own that keeps its files between conversations; browse, preview, upload, and download them."
---

Every employee has a computer of its own: a private cloud workspace where it reads files, runs code, works through spreadsheets, and saves what it makes. The same computer is used in all of the employee's work with you, so files from earlier work are still there next time. Ask in a new conversation for "the report you wrote last week", and the employee finds it.

## Which work uses the computer

| Work | Computer |
| --- | --- |
| Your [direct messages](/ai-employees/direct-messages) with the employee, in every conversation | The employee's computer |
| Its [routines](/ai-employees/routines) | The employee's computer |
| [Group chats](/ai-employees/group-chats) with only you and your employees | The employee's computer |
| Group chats you [invited people to](/ai-employees/invite-people), [Slack](/ai-employees/slack) conversations | A separate computer for each conversation, so other people never see the files from your private work |

The computer goes to sleep when nobody uses it and wakes up when the employee needs it. Waking takes a few seconds; the first message of a conversation says "Getting … computer ready" while it does.

## Browse the files

Open the employee's workspace (**Manage** in its direct message) and click **Computer**. Or, in the direct message, click the files button at the top to open the same files beside the chat.

The header shows the computer's state: **Running**, **Asleep**, or **Not started** for an employee that hasn't used it yet. Opening the files wakes the computer.

Everything lives in the **Home** folder. Click a folder to open it, and a file to preview it.

| You can | How |
| --- | --- |
| Preview a file | Click it. Images, PDFs, videos, audio, Markdown, code, CSV, and Excel files open in the preview. Other files can be downloaded. |
| Upload files | Click **Upload**, or drop files on the list. They go to the folder you have open. |
| Make a folder | Click **New folder**. |
| Rename or delete | Use the buttons on the file's row. Deleting a folder deletes everything in it. |
| Download | Use the download button on a file's row. For a folder, download it as a zip. |
| See hidden files | Click **Show hidden files**. |

A name that's already taken gets " (2)" added. The **skills** folder is read-only, because Easy-Peasy.AI keeps the skills in it up to date. A folder shows its first 2,000 items.

## Good to know

- Only you see your employees' computers. People you invite to a group chat work on that group chat's own computer.
- Files your employee delivers in a chat are also on its computer, in the folder for that job.
- Deleting an employee deletes its computer and every file on it. Download what you want to keep first.
- The computer is for the employee's work. Keep files you need for the long term in your own storage, such as Google Drive or OneDrive, which your employee can also [work with](/ai-employees/apps).
