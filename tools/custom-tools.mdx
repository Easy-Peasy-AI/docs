When no built-in tool fits a job you do often, make your own. Describe it in a sentence; the fields, the instructions, and the form are built for you. You can then adjust it, use it like any other tool, and share it.

## Create a tool

<Steps>
  <Step title="Open Create Tool">
    Click **All Tools** in the sidebar, then **Create Tool** at the top right.
  </Step>
  <Step title="Describe the tool">
    Type what it should make in **What do you want to create?**, such as "yoga class description for a studio schedule". Click **+ add instructions** to say which fields you want and how the result should read.

    <Frame>
      <img src="/images/tools/magic-ai-tool.webp" alt="Magic AI Tool: Create any AI Tool from a single prompt, with the request yoga class description for a studio schedule, instructions to include fields for the class name, level, length in minutes, and focus, and to write a short, warm description, a Create button, and examples such as ad copy and business plan" />
    </Frame>
  </Step>
  <Step title="Click Create">
    The new tool opens a few seconds later, ready to try.

    <Frame>
      <img src="/images/tools/custom-tool-form.webp" alt="The Yoga Class Description Generator tool with Edit and Save buttons, Class Name Slow Flow, Level All Levels, Length 60 minutes, Focus of the Class, Use advanced AI model? off, Examples (optional), outputs 1, language English, and Generate" />
    </Frame>
  </Step>
  <Step title="Try it, then click Save">
    Fill in the fields and click **Generate** to check the results. When you're happy with it, click **Save**. Saved tools appear on the Tools page under **My Tools**.

    <Frame>
      <img src="/images/tools/custom-tool-output.webp" alt="A result from the custom tool: Class Name Slow Flow, Level All Levels, Length 60 Minutes, and a class description inviting students to unwind with soothing stretches, breath work, and an extended relaxation, with the usual result buttons" />
    </Frame>

    <Warning>
      A tool you don't save isn't kept. Click **Save** before you leave the page.
    </Warning>
  </Step>
</Steps>

## Edit a tool

Click **Edit** at the top of the tool.

<Tabs>
  <Tab title="AI Edit">
    Describe the change and click **Apply Changes**. For example: "Remove the Class Description field. Show Level as radio buttons."

    <Frame>
      <img src="/images/tools/custom-tool-ai-edit.webp" alt="The Edit Template window on AI Edit, with the request Remove the Class Description field. Show Level as radio buttons, and Cancel and Apply Changes" />
    </Frame>
  </Tab>
  <Tab title="Manual Edit">
    Change the **Title**, **Description**, and **Output**, and each field's **Label**, **Type**, **Placeholder**, and **Character Limit**. **Add Field** adds a field, the arrows reorder them, and the trash icon removes one. Click **Save Changes**.

    <Frame>
      <img src="/images/tools/custom-tool-manual-edit.webp" alt="The Edit Template window on Manual Edit: Title Yoga Class Description Generator, Description, Output Text, Add Field, and Field 1 Class Name as a Text Input with a placeholder and a 100-character limit" width="560" />
    </Frame>
  </Tab>
</Tabs>

A tool can have up to 9 fields. Field types are **Text Input**, **Text Area**, **Dropdown Select**, **Checkbox**, **Radio Button**, and **Image Upload**.

**Output** decides what the tool makes:

| Output | What it makes | What it uses |
| --- | --- | --- |
| **Text** | Written text | Words |
| **Image (from description)** | An image from the fields | 3 image & video credits |
| **Image (transform uploaded photo)** | An edited version of an uploaded photo. Needs an **Image Upload** field | 3 image & video credits |
| **Speech (voiced audio)** | A script, read aloud | Words for the script, and text-to-speech characters for the audio |

To delete a saved tool, click the trash icon at the top of it and confirm.

## Use a tool

Your tools work like the built-in ones: fill in the fields, choose the number of results and the language, and click **Generate**. See [Run a tool](/tools/run).

- **Use advanced AI model?** switches text tools to a stronger model, which uses more words.
- **Examples (optional)**: add examples of results you like, and the tool follows their format.
- Results in a language other than English are made one at a time.

## Share a tool

Click **Share** at the top of a saved tool.

<Frame>
  <img src="/images/tools/custom-tool-share.webp" alt="The Share Template window for Yoga Class Description Generator with two switches, Share with anyone and Share with your team, both off" width="520" />
</Frame>

- **Share with your team** adds the tool to your teammates' **My Tools**. They use it with their own account, and can't edit or delete it.
- **Share with anyone** gives you a link to a public page where anyone can use the tool without an account.

<Warning>
  Results made through a public link use **your** words and credits, and appear in your History. Each person can make up to 20 results a day, and a link up to 300 a day. Visitors always get the standard model and at most 2 results at a time. Turn the switch off to stop the link working.
</Warning>
