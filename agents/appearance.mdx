**Appearance** controls what visitors see in the chat: the header, the first message, the buttons under the text box, and the colors. The preview on the right updates as you edit. Click **Save** at the bottom to publish your changes to every website chat.

The chat bubble on your website is set here too, under [**Chat bubble**](#chat-bubble): where it sits, its size, icon, color, and text. To put it on your site, copy the install code from [**Channels** > **Website**](/agents/website#add-the-chat-bubble).

## Content

| Setting | What it does |
| --- | --- |
| **Agent Avatar** | The picture in the chat header, and next to the agent's messages if you turn that on |
| **Agent Name** | The name in the chat header |
| **Description** | The line under the name in the header |
| **Greeting Message** | The first message visitors see. **Add another message** adds up to 4 more; each shows as its own message, and as its own pop-up next to the closed chat bubble |
| **Suggested Messages** | Questions visitors can tap to start, one per line |
| **Suggested messages layout** | **Scroll in one row** keeps the greeting in view; **Show all** wraps every suggestion onto rows |
| **Auto show initial messages pop-ups after (in seconds)** | How long before the greeting pops up next to the closed chat bubble. Enter a negative number to turn this off |
| **Message Placeholder** | The hint text in the message box |
| **Notice above the message box** | Optional, up to 200 characters, for example a privacy notice. Visitors can close it; it shows again if you change the text |
| **Footer text** | Optional, up to 200 characters, under the message box. Use it for links such as your docs or status page |

The notice and the footer can hold links written as `[privacy policy](https://example.com/privacy)`, plain `https://` addresses, `**bold**` and `*italic*`.

### Starting over and earlier chats

Visitors can start a new chat, or go back to one they had before, from the **•••** menu in the chat header (**Start a new chat** and **Recent chats**). Earlier chats are kept in the visitor's own browser, up to 20 per agent; you see every conversation in [Conversations](/agents/conversations) either way. In the Playground, **Start a new chat** clears the test chat.

## Chat features

| Switch | What it does |
| --- | --- |
| **Show Copy Button** | A copy button under the agent's answers |
| **Collect User Feedback** | Thumbs up and down under answers. The counts appear in [Analytics](/agents/analytics) |
| **Allow Message Regeneration** | Lets visitors ask for a new version of an answer |
| **Enable Voice Input** | A microphone button that turns speech into typed text |
| **Allow image attachments** | Lets visitors send screenshots and photos |

### Image attachments

With **Allow image attachments** on, visitors can attach up to 4 images per message (PNG, JPEG, or WebP, up to 5 MB each) in the website chat, on the shareable link, on [Telegram](/agents/telegram), and on [Messenger](/agents/messenger). The agent looks at them and answers.

- The agent's model must be able to see images: GPT, Claude, or Gemini models. With another model, the attach button doesn't appear.
- Each image the agent looks at uses 200 words, on every model. The agent keeps up to 3 recent images in view, so an image is counted again for each reply it's still in view for.

| Setting | What it does |
| --- | --- |
| **Theme** | Light or dark chat |
| **Corner radius** | **Sharp**, **Soft**, **Round**, or **Pill**: the corners of the chat window, messages, suggested messages, and the message box. **Round** is the original look. The chat window's corners reach your website within about a minute |
| **Agent bubble style** | Background and text color of the agent's messages |
| **Header style** | Background color of the header. Empty uses the agent bubble color |
| **Chat font** | The font of the whole chat: a preset such as Inter, or **Custom web font…** with a font name and a stylesheet URL |
| **Profile icon size** | Size of the avatar in the header, from **Small** to **3X Large** |
| **Show avatar next to agent messages** | Shows an avatar beside each answer. **Message Avatar** sets a different picture for it |
| **Human bubble style** | Background and text color of the visitor's messages |

## Chat bubble

The chat bubble is the button that opens the chat on your website. Saved changes reach your website within about a minute, without changing the install code.

| Setting | What it does |
| --- | --- |
| **Position** | **Bottom Right**, **Bottom Left**, **Top Right**, **Top Left**, or a tab on the edge of the page: **Side Right**, **Side Left** |
| **Chat bubble size** | **Medium**, **Large**, or **Extra Large** (not for side tabs) |
| **Chat window width** | **Default** (400px), **Wide** (480px), or **Extra wide** (560px) on computers. On phones the chat always opens full screen |
| **Chat bubble icon** | Pick one of the built-in icons, or click **+** to upload your own (PNG, JPG, WebP, or GIF, up to 5 MB). An uploaded image can **Fill the bubble**, which suits photos, or **Fit inside**, which suits logos. Agents made before these icons arrived keep **Classic**, the original icon, until you pick another; newer agents start with **Spark**. Side tabs show text only |
| **Chat bubble color** | The bubble's color. Until you pick one, it matches your agent's header color; the reset button goes back to it |
| **Show text in the chat bubble** | Adds a label next to the icon, such as "Chat with us", up to 40 characters, with the icon on the left or the right. It folds away while the chat is open. A side tab always shows its text: set it in **Text on the side tab** |

While the **Appearance** tab of the [Playground](/agents/playground) is open, the bubble appears under the chat preview; click it to see it with the chat open.

The icon and text turn white or dark on their own, so they stay readable on the color you pick. If you pasted an older install code that sets a position, size, width, color, or icon, it keeps working: whatever you save here takes priority over it.
