---
title: "Voice calls"
description: "Let visitors talk to your agent out loud from the website chat, with the voice, language, and call limits you choose."
---

With voice calls, visitors tap **Talk** in the chat and talk to your agent. The agent listens, answers in the voice you pick, and uses the same knowledge and actions as in text chat. Visitors can still type during a call, for names, emails, or links.

For a phone number people can dial, see [Phone calls](/agents/phone-calls).

<Note>
  Website visitors can call your agent on the Unlimited 200 and higher plans, Teams 200 and Teams 300, and Enterprise. On other plans, including Free, you can try voice calls in the Playground: 10 minutes every 30 days across all your agents, up to 3 minutes per call.
</Note>

## Turn on voice calls

<Steps>
  <Step title="Open Voice">
    Open your agent and click **Voice**. You can also use the **Voice** tab in the [Playground](/agents/playground#set-up-voice-calls), which saves automatically.

    <Frame>
      <img src="/images/agents/voice.webp" alt="The Voice page: a banner saying voice calls on your website are available from Unlimited 200, the Enable voice calls switch on, a note that spoken replies use words at 2x the text rate, and Agent voice set to Hope, English, American, with a speaking speed of 1.00x" width="620" />
    </Frame>
  </Step>
  <Step title="Turn on Enable voice calls">
    A **Talk** button appears next to the message box. It turns into the send button as soon as the visitor types, and stays hidden while the agent is writing a reply.

    **Talk** is in English. If your visitors speak another language, write your own word in **Call button text**.
  </Step>
  <Step title="Pick a voice">
    Under **Agent voice**, click **Change**, play a few voices, and click **Select**.

    <Frame>
      <img src="/images/agents/voice-picker.webp" alt="The Agent voice window with the tabs Voice library, My voices, and More voices, a search box, and voices such as Hope, Heather Rey, Matthew - Smooth, and Pro Narrator, each with a play button" width="500" />
    </Frame>

    | Tab | Voices |
    | --- | --- |
    | **Voice library** | About 1,900 voices in many languages and accents |
    | **My voices** | Voices you cloned with an Instant clone in [text to speech](/audio/voices#instant-clone). Professional clones can't be used for calls |
    | **More voices** | Other voice families, with natural accents in several languages |
  </Step>
  <Step title="Click Save">
    Test a call in the Playground. Reload any open preview of your website chat to see the **Talk** button there.
  </Step>
</Steps>

## Settings

| Setting | What it does |
| --- | --- |
| **Call button text** | The word on the call button next to the message box, up to 16 characters. Empty shows **Talk** |
| **Allow text input during calls** | Keeps the message box usable during a call |
| **Allow interruptions** | Lets callers talk over the agent to cut it off |
| **Voice model** | The model used on calls. **Same as chat** uses the agent's model; the others are fast models, because every second the model thinks is a second of silence |
| **Sync with chat instructions** | Uses the agent's instructions on calls. Turn it off to write separate **Voice instructions**, for example "Keep answers to two sentences" |
| **Spoken language** | The language callers speak. **Multilingual** detects it; choosing the language makes recognition more accurate |
| **Silence before the agent answers** | How long a pause means the caller has finished. Shorter feels snappier; longer tolerates pauses |
| **Noise sensitivity** | How easily background noise counts as speech |
| **Speaking speed** | Slower or faster than the voice as recorded, for voices that support it |
| **Greeting** | What the agent says first. Empty reuses the chat's greeting |
| **Error message** | What the agent says when it doesn't catch something |
| **End the call after silence (seconds)** | Ends the call after this much silence. `0` keeps the line open until the caller hangs up |
| **Maximum call length (minutes)** | The longest a call can last, from 1 to 60 minutes |
| **Calls per visitor per day** | How many calls one visitor can make each day. It doesn't apply in the Playground |

## What calls cost

Spoken replies use your plan's words at twice the rate of a text reply, on every model, including models that don't use words in text chat. Listening, the voice, and the call itself are included.

Calls appear in [**Conversations**](/agents/conversations) under **Web**, with **Voice call** as the source.

<AccordionGroup>
  <Accordion title="There's no Talk button in the chat">
    Check that **Enable voice calls** is on and saved, then reload the page with the chat. On plans below Unlimited 200, the **Talk** button appears only in the Playground.
  </Accordion>
  <Accordion title="The browser didn't ask for the microphone">
    Calls need microphone access. Allow it in the browser's site settings and try again. If you embed the chat with an iframe, keep `allow="microphone"` on it.
  </Accordion>
  <Accordion title="The agent answers too slowly">
    Pick a faster **Voice model**, shorten the **Voice instructions**, and lower **Silence before the agent answers**.
  </Accordion>
</AccordionGroup>
