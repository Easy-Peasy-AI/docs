---
title: "Website platforms"
description: "Add your agent's chat to Wix, Squarespace, Webflow, WordPress, and other website builders."
---

Every platform needs the same thing: your agent's install snippet, pasted where the platform adds code before the closing `</body>` tag. Copy the snippet first from **Channels** > **Chat bubble** > **Manage** > **Install snippet**. See [Add your agent to your website](/agents/website).

For a chat inside a single page instead of a floating bubble, use the **Iframe embed** code in the platform's HTML or embed block.

## WordPress

Install the free **Easy-Peasy.AI Chatbot** plugin from **Plugins** > **Add Plugin** and paste your Agent ID into **Settings** > **Easy-Peasy.AI Chatbot**. No snippet needed. See [WordPress](/agents/wordpress).

## Wix

<Steps>
  <Step title="Open Custom code">
    In your Wix site's dashboard, go to **Settings** and open **Custom code** (search for "custom code" in the settings).
  </Step>
  <Step title="Add the snippet">
    Click **Add Code**, paste the install snippet, and give it a name. Under **Add Code to Pages**, choose **All pages** and **Load code once**. Set **Place Code in** to **Body - end**, then click **Apply**.
  </Step>
  <Step title="Check your live site">
    Open your published site. The chat bubble appears on every page.
  </Step>
</Steps>

If you don't see **Custom code**, your Wix plan may not allow it. Use the Wix Editor instead: **Add Elements** > **Embed Code** > **Embed HTML**, paste the iframe code, and publish.

## Squarespace

<Steps>
  <Step title="Open Code Injection">
    In your Squarespace dashboard, open **Code Injection** (search for "code injection" in the settings).
  </Step>
  <Step title="Paste the snippet into Footer">
    Paste the install snippet into the **Footer** field and click **Save**.
  </Step>
  <Step title="Check your live site">
    Open your site. The chat bubble appears on every page.
  </Step>
</Steps>

For a chat inside one page, edit the page, add a **Code** block, and paste the iframe code. Squarespace allows code injection and scripts only on some plans; if you don't see the option, check your plan.

## Webflow

<Steps>
  <Step title="Open Custom code">
    Open your site's **Site settings** and the **Custom code** tab.
  </Step>
  <Step title="Paste the snippet into Footer code">
    Paste the install snippet into **Footer code** and click **Save changes**.
  </Step>
  <Step title="Publish">
    Custom code goes live only when you publish. Click **Publish**, then open your live site.
  </Step>
</Steps>

To add the chat to one page only, paste the snippet into that page's **Before `</body>` tag** setting, or drag an **Embed** element onto the page and paste the iframe code. Webflow allows custom code on paid site plans.

## Shopify

Shopify has its own channel, which also lets the agent search your products and look up orders. See [Shopify](/agents/shopify).

## Other websites

For any other site, paste the install snippet before `</body>` in your page template, or in your builder's footer or custom code setting. On single-page apps (React, Vue, Next.js), add the snippet once to the main HTML template or layout so it loads on every page.
