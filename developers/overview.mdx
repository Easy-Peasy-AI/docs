## Get an API key

Open [**Settings** > **API/MCP**](https://easy-peasy.ai/settings/api) in the dashboard and create a key. Send it in the `x-api-key` header. Keep keys on your server, never in browser code or public repositories.

## What the API covers

| Area | What you can do | Start here |
| --- | --- | --- |
| Text | Run the dashboard's writing tools, from blog posts to SOAP notes | [Generate text](/api-reference/endpoint/generate) |
| Images | Generate and edit images with Nano Banana, GPT Image, FLUX, Seedream, and more | [Generate image](/api-reference/endpoint/generate-image) |
| Video | Text-to-video, image-to-video, and reference-to-video with the dashboard's video models | [Video models](/api-reference/video-models) |
| Talking videos | Animate a face with your script or audio | [Generate talking video](/api-reference/endpoint/generate-talking-video) |
| Audio | Text to speech, sound effects, and transcription | [Text to speech](/api-reference/endpoint/generate-tts) |
| Chat | OpenAI-compatible chat completions with streaming | [Chat Completions](/api-reference/endpoint/chat-completions) |

<Note>
  In the dashboard, the text generators are called **tools**. In the API they're called **presets**, because that's the name of the request field (`preset`).
</Note>

## Quick example

```bash
curl -X POST https://easy-peasy.ai/api/generate \
  -H "Content-Type: application/json" \
  -H "x-api-key: YOUR_API_KEY" \
  -d '{
    "preset": "blog-post",
    "keywords": "How to get started with AI",
    "tone": "professional",
    "outputs": 1
  }'
```

API calls use the same allowance as the dashboard. See [Plans and credits](/account/plans-and-credits) for how usage is counted.
