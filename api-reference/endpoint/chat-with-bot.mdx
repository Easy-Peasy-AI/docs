title: 'Chat with an agent'

Send a message to an [agent](/agents/overview) you built in the dashboard and get its answer. Agents were called Bots, which is why the path starts with `/bot`.

<Note>
  The Agents API uses a **different base URL** (`https://bots.easy-peasy.ai`) but the **same API key** as all other Easy-Peasy.AI endpoints.
</Note>

## Find your agent's ID

`public_url` is your agent's ID. In the dashboard, open your agent and go to **Channels** > **Chat bubble** > **Manage** and copy **Your Agent ID**, or open **Integrations** > **REST API** to see the full endpoint with example code.

## Streaming

When `stream: true` is set, the response is returned as **server-sent events (SSE)**. Each event contains a chunk of the agent's answer, so you can show it as it's written.

## Conversation history

To keep context across messages, send the earlier messages in `history`. Each entry has a `role` (`human` or `ai`) and a `text` field. Each request is answered on its own, so without `history` the agent doesn't know what was said before.

## What the API doesn't do

The agent answers from its knowledge and instructions. [Actions](/agents/actions), such as buttons, forms, and bookings, don't run through the API.
